Salary Lens

Welcome! One step to get started

Salary Lens shows the expected salary on job pages. Salaries listed on a posting show up right away. For a market estimate with sources, add your own Gemini API key below. It's stored only in this browser.

Gemini API key

  1. Open Google AI Studio and create an API key.
  2. Paste it below and select Save and test.

Keep your key safe

  • Salary Lens will never ask for your key on a website. Only paste it on this settings page.
  • In Google Cloud credentials, restrict the key to the Generative Language API only, so it's useless for anything else if it leaks.
  • If billing is on, set a budget alert for peace of mind.
  • Think your key leaked? Delete it in Google AI Studio and create a new one.

Live Google Search lookups with source links need a key with billing turned on in Google Cloud (Google includes a monthly allowance of free searches). Free keys still work, with AI-only estimates that are labelled as such.

Lookups

When off, click the badge next to the job title to look it up. This saves quota while you browse.

Show amounts

Salary Lens stops calling Gemini after this many lookups in 24 hours (and after 6 a minute or 30 an hour), so no page can run up your bill. Saved lookups don't count.

A Flash model is fast and cheap. Change this if Google retires the model.

Saved lookups

Estimates are kept for 7 days so reopening a job doesn't use quota.

Privacy

When you look up a salary, Salary Lens sends the job title, company, location, experience and any listed salary to Google's Gemini API, using your key. Nothing is sent to the makers of Salary Lens, and there are no analytics. Your key and saved lookups stay in this browser.
